A one-page visual framework that sorts ten machine learning algorithms by learning type, application domain, and real-world use.

Overview

Choosing an algorithm starts with two questions: what kind of data do I have, and what kind of answer do I need? This map answers them for ten widely used methods, five classic approaches for tabular data and five deep learning models for images, language, and content generation.

Supervised learning

Learns from labeled examples, inputs paired with known answers, so it can predict the answer for new inputs.

In this map: Decision Tree, Random Forest, Gradient Boosting, CNN, BERT

Unsupervised learning

Finds structure in unlabeled data, such as natural groups, simpler views, or patterns it can reproduce.

In this map: K-means, PCA, GPT, Diffusion, GAN

Part 1: Classic machine learning on tabular data

Rows and columns, such as customer records, transactions, and measurements.

Decision Tree

Supervised
Tabular Data

How it works. Asks a chain of yes/no questions about the data, splitting it into purer and purer groups until each branch ends in a prediction.

Real-world use. Approving or declining loan applications; rule-based medical triage.

Random Forest

Supervised
Tabular Data

How it works. Trains many decision trees on random samples of the data and takes a majority vote, so individual mistakes cancel out. An ensemble of Decision Trees.

Real-world use. Credit card fraud detection; predicting which customers will cancel.

Gradient Boosting (XGBoost)

Supervised
Tabular Data

How it works. Builds trees one after another, each new tree correcting the errors the previous ones left behind. Often the most accurate on tables.

Real-world use. Insurance risk scoring; demand forecasting; ranking search results.

K-means Clustering

Unsupervised
Tabular Data

How it works. Picks K centers, assigns every point to its nearest center, moves each center to the average of its points, and repeats until the groups settle.

Real-world use. Customer segmentation for marketing; grouping similar products.

Principal Component Analysis (PCA)

Unsupervised
Tabular DataComputer Vision

How it works. Finds the few directions along which the data varies most and rewrites it with fewer columns while keeping most of the information.

Real-world use. Compressing high-dimensional data; plotting data in 2D; compressing face images.

How to choose

  • Known answers to learn from? Use supervised methods: Decision Tree, Random Forest, Gradient Boosting.
  • No labels, looking for groups or simpler views? Use unsupervised methods: K-means, PCA.
  • The tree family: one tree is easy to read, a forest is steadier, and boosting is usually the most accurate.

Part 2: Deep learning for vision, language, and generative AI

Images, text, and models that create new content.

Convolutional Neural Network (CNN)

Supervised
Computer Vision

How it works. Slides small filters across an image to detect edges, then shapes, then whole objects, one layer at a time.

Real-world use. Reading medical scans; spotting defects on factory lines; object detection for self-driving cars.

BERT

Supervised (fine-tuned)
NLP

How it works. A Transformer that reads text in both directions at once to grasp meaning in context. Pre-trained on huge text, then fine-tuned on labeled examples.

Real-world use. Sentiment analysis of reviews; search relevance; sorting support tickets.

GPT (Large Language Model)

Unsupervised (self-supervised)
NLPGenerative AI

How it works. A Transformer trained to predict the next word across massive amounts of text, which teaches it to write, summarize, and answer questions.

Real-world use. Chat assistants; code generation; document summarization.

Diffusion Model (Stable Diffusion)

Unsupervised (self-supervised)
Generative AIComputer Vision

How it works. Learns to remove noise step by step. To create an image, it starts from pure noise and denoises it toward a text prompt.

Real-world use. Text-to-image art; product mockups; photo editing.

Generative Adversarial Network (GAN)

Unsupervised
Generative AIComputer Vision

How it works. A generator makes fakes while a discriminator tries to catch them. Competing pushes both to improve until the fakes look real.

Real-world use. Synthetic faces; extra training data when real data is scarce; image upscaling.

How these relate

  • BERT and GPT are both Transformers. BERT reads and understands text, while GPT generates it.
  • GANs and diffusion models both create images. GANs pit two networks against each other, while diffusion denoises step by step and is more stable to train.
  • All five rely on deep neural networks trained on large amounts of data.
Blue = supervised, orange = unsupervised (each card also states its type in words). Self-supervised learning, used by GPT and by the denoising step of diffusion models, is a form of unsupervised learning in which the data supplies its own labels, such as the next word in a sentence. BERT is pre-trained this way and then fine-tuned with labeled examples, so it is listed as supervised.

Reflection

Building this map moved me from knowing algorithms by name to understanding how to choose among them. The biggest lesson was that the first question is not which algorithm is best, but what kind of data and what kind of answer I have. Labeled tabular data points toward supervised methods such as decision trees, random forests, and gradient boosting, while unlabeled data calls for clustering or PCA. For images, language, and content creation, deep learning families such as CNNs, Transformers, GANs, and diffusion models take over.

The relationships helped me most. Random forests and gradient boosting are both built from decision trees, which connects directly to the decision tree I described in Assignment 1.4. BERT and GPT share the Transformer design but serve different purposes. The hardest labeling decision was GPT, because it learns from text without human labels. I classified it as self-supervised, which is a form of unsupervised learning.

As a software engineer, I use LLMs every day, so seeing where they fit among other algorithms gives me a clearer sense of when a simpler model is the better tool.
